# **1\. 概述**

## **1\.1 SDK 简介**

本 SDK 是针对智动力机器人的 C\+\+ 二次开发工具包，提供基础控制、状态获取、遥操作等接口，帮助用户完成机器人基础运控、数据采集及基本调试。

## **1\.2 核心能力**

- **通信层**：基于 DDS 的实时消息传递，连接用户电脑与机器人控制器

- **控制层**：支持 CSP（位置模式）/ CST（力矩模式），含点动、轨迹跟踪、混合轨迹等运动功能

- **状态反馈**：实时获取关节位置/速度/力矩、底盘传感器、错误码等完整机器人状态

- **安全机制**：急停、任务中止、软限位、错误码检测等多层安全保护

## **1\.3 适用场景**

- 机器人数据采集

- 遥控操作（遥操作）

- 基础运控算法开发与调试

- 传感器数据订阅与处理

## **1\.4 兼容性说明**

|项目|说明|
|---|---|
|语言|C\+\+|
|通信中间件|DDS\(Data Distribution Service\)|
|控制器|Cerebellum（小脑/运动控制单元）\+ Orin（大脑 / Jetson Orin）|

# **2\. 架构与设计**

## **2\.1 整体架构**

下图展示了机器人的软件架构。整个系统由 **Cerebellum（小脑/运动控制单元 ）**、**Brain（大脑 / 传感器管理与数据采集单元）**以及 **User PC（用户电脑）**三部分构成。本 SDK 属于 Cerebellum\<\-\-\>Brain侧\(机器人小脑\<\-\-\>机器人大脑\)的开发套件，即图中 DDS Controller Client。

\- **Cerebellum（运动控制单元 / 小脑）**：负责机器人底层运动控制，处理来自 Orin / User PC 的运动指令，并返回机器人状态给 Orin / User PC。

\- **Orin（大脑 / 传感器管理与数据采集单元）**：统一管理机器人各类传感器（如相机、激光雷达、VR 设备等），并实时发布传感器数据，支持用户二次开发与数据采集。

\- **User PC（用户电脑）**：通过本 SDK 与 Orin 进行指令下发及状态上传，实现对机器人的远程控制与应用开发。

> 注：图中带箭头线段表示 DDS 消息的传递，图中均为双向箭头，表示消息的传递是双向的，线段旁所附内容代表传递的 DDS 消息体。

## **2\.2 通信机制**

SDK 通过 DDS 协议与控制器进行双向实时通信：

- **下行（指令）**：用户调用 SDK 接口 → DDS 发布控制指令 → Cerebellum / Brain 执行

- **上行（状态）**：Cerebellum / Brain 发布机器人状态 → DDS 订阅 → SDK 回调 / `getRobotState()`读取

## **2\.3 关键术语表**

|术语|说明|
|---|---|
|CSP|Cyclic Synchronous Position，周期同步位置控制模式|
|CST|Cyclic Synchronous Torque，周期同步力矩控制模式|
|DDS|Data Distribution Service，数据分发服务|
|domain\_id|DDS 域 ID，用于隔离不同 DDS 网络的通信，通常取目标 IP 最后一段|
|Hybrid Trajectory|混合轨迹，SDK 以\~100Hz 频率周期调用用户回调并发布轨迹指令|
|MoveL|笛卡尔直线运动，给定目标位姿与速度由 SDK 内部逆解并下发执行|
|重力补偿|抵消机械臂自重，使机械臂可被轻松手动引导|
|CSP 软限位|限制 CSP 模式下关节位置指令的输出范围|
|CST 力矩限幅|限制 CST 模式下关节力矩指令的输出范围|

## **3\.2 安装依赖**

项目依赖 CycloneDDS\(v0\.10\.5\), 需自行编译安装，例如：

```Bash
wget https://github.com/eclipse-cyclonedds/cyclonedds/archive/refs/tags/100.10.5.zip -O cyclonedds-0.10.5.zip
unzip cyclonedds-0.10.5.zip
cd cyclonedds-0.10.5
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX="$HOME/software/cyclonedds_install"
cmake --build . --target install -j$(nproc)
```

此外，用户需要自行编写cyclonedds配置文件，并且将该xml路径写入CYCLONEDDS\_URI环境变量，可参考[官方文档](https://cyclonedds.io/docs/cyclonedds/0.10.5/config/cyclonedds_specifics.html)

构建 SDK 核心库还需 spdlog（编译期依赖，公开头文件不依赖 spdlog），UI 还需要 nlohmann\-json。

## **3\.6 最小控制流程**

典型控制流程为：**创建控制器 → 连接 → 使能 → 运动执行 → 去使能 → 断开连接**。

完整示例参见：

```C++
#include "dds_controller.h"

#define _USE_MATH_DEFINES
#include <cmath>

#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <fstream>
#include <iostream>
#include <mutex>
#include <sstream>
#include <string>
#include <thread>
#include <chrono>
#include <atomic>
#include <vector>
#include <algorithm>
#include <memory>

int main()
{
    // 1. 创建控制器
    auto controller = DdsController::createDdsController(88);

    // 2. 连接
    controller_dds::StartConfig config;
    config.config_name = "ir_no_ee";
    config.robot_type = 1;

    config.ee_type = 0;
    config.enable_csp_output_limit = true;
    config.enable_cst_output_limit = false;
    config.enable_error_code_check = false;
    config.enable_encoder_check = true;
    config.enable_domain_counter_check = true;
    config.gravity_compensation_enabled = false;
    std::this_thread::sleep_for(std::chrono::seconds(5));
    controller->getRobotState();
    printf("DDS 初始化完成，等待 discovery...\n");
    std::this_thread::sleep_for(std::chrono::seconds(3));
    controller->connect(config);
    std::this_thread::sleep_for(std::chrono::seconds(40));
  
  

    printf("连接成功，等待从站初始化...\n");
  
    // 3. 使能 CSP
   controller->enable(controller_dds::RequestMode::kCSP);

    std::this_thread::sleep_for(std::chrono::seconds(5));

    // 获取底盘传感器数据
    auto* dds = static_cast<DdsController*>(controller.get());
    const auto& sensor = dds->getChassisSensor();
    printf("底盘传感器: 左轮=%.3f rad/s, 右轮=%.3f rad/s\n",
           sensor.left_wheel_speed, sensor.right_wheel_speed);
    for (int i = 0; i < 8; ++i) {
        printf("  超声波[%d]: %.1f mm\n", i, sensor.ultrasonic[i]);
    }

    // 4. 底盘转圈：左转 2s → 右转 2s
    constexpr double kWheelSpeed = 0.5;  // 轮子速度 rad/s

    auto rotate_cb = [](const controller_dds::RobotState&,
                         controller_dds::Duration dt,
                         controller_dds::JointPositionCmd& cmd) {
        if (!cmd.isInitialized()) {
            cmd.enableWheel();
            cmd.setInitialized();
        }

        double t = dt.toSec();

        if (t < 2.0) {
            // 左转：左轮向后，右轮向前
            cmd.wheel.dq_d[0] =  kWheelSpeed;
            cmd.wheel.dq_d[1] =  kWheelSpeed;
            printf("[%.1fs] 左转中... 左轮: %.1f, 右轮: %.1f rad/s\n",
                   t, cmd.wheel.dq_d[0], cmd.wheel.dq_d[1]);
        } else if (t < 4.0) {
            // 右转：左轮向前，右轮向后
            cmd.wheel.dq_d[0] =  -kWheelSpeed;
            cmd.wheel.dq_d[1] = -kWheelSpeed;
            printf("[%.1fs] 右转中... 左轮: %.1f, 右轮: %.1f rad/s\n",
                   t, cmd.wheel.dq_d[0], cmd.wheel.dq_d[1]);
        } else {
            // 停止
            cmd.wheel.dq_d[0] = 0.0;
            cmd.wheel.dq_d[1] = 0.0;
            cmd.motionFinish();
            printf("[%.1fs] 转圈完成，停止\n", t);
        }
    };

    printf("开始底盘转圈 demo\n");

    // 配置 HybridTrajectory：开启轮子控制
    controller_dds::HybridTrajectoryConfig traj_cfg;
    traj_cfg.enable_wheel = true;
    dds->startHybridTrajectory(rotate_cb, traj_cfg);

    // 等待运动完成（最多等 5 秒）
    std::this_thread::sleep_for(std::chrono::seconds(5));

    // 5. 清理
    controller->disable();
    controller->disconnect();
    printf("demo 结束\n");
    return 0;
}
```

# **4\. API 参考**

## **4\.1 命名规范与通用约定**

|类别|规范|示例|
|---|---|---|
|公有方法|小驼峰\(camelCase\)|`connect()`, `getRobotState()`|
|私有方法|小驼峰\(camelCase\)|`initializeDds()`, `sendSignal()`|
|回调类型|大驼峰\+ `Function` 后缀|`JointPositionsFunction`|

**阻塞与非阻塞约定：**

- **阻塞接口**：调用后等待操作完成才返回（如 `returnToZero()`）

- **非阻塞接口**：调用后立即返回，操作在后台持续执行（如 `startHybridTrajectory()` 启动后台线程以 100Hz 周期调用回调）

- **回调接口**：用户传入回调函数，由 SDK 在控制循环中周期性调用（如 `runCycleJointMotion()`）

**返回值约定：**

- `int` 类型：`0` 表示成功，负值表示错误码

- `bool` 类型：`true` 表示成功，`false` 表示失败

- `void` 类型：无返回值（通常为单向指令下发或无需确认状态的操作）

## **4\.2 初始化与通用接口**

该模块主要用于 DDS 的初始化与通信实体的创建，是机器人系统能够正常通信的前置条件。

|函数签名|返回类型|简要说明|

|`DdsController(int domain_id = 0)`|构造函数|指定 DDS 域 ID。`domain_id`：DDS 域 ID，默认 0，通常取目标 IP 最后一段。CycloneDDS 网络配置通过环境变量 CYCLONEDDS\_URI 控制|
|`~DdsController()`|析构函数|析构函数，自动停止混合轨迹|
|`static std::string getSdkVersion()`|`std::string`|获取 SDK 版本号字符串，如`"r26.6"`|

## **4\.3 连接与生命周期管理**

该模块涉及机器人的基础控制流程：从上电后连接控制器、使能模组、断开连接、下使能模组。这些操作是机器人能够正常运控的前置条件。

\> ⚠️ **控制流程要求**：应用程序在运控前，应确保机器人已完成连接并处于使能状态；在退出控制或关闭系统前，应先停止运动并执行去使能和断开连接操作，以保证系统安全。

|函数签名|返回类型|简要说明|
|---|---|---|
|`connect(``controller_dds``::StartConfig config)`|`int`|连接控制器。`config` 为启动配置参数（详见 [StartConfig](https://dcni84d5zjg4.feishu.cn/docx/OFSadeELDow2YJxuLUDcgZmQnMf#share-FUlidvVvGoFquCxmIDNc2IphnGg)）。返回 `0` 成功，`-11` DDS 初始化失败，`-12` 配置类型不支持|
|`disconnect()`|`int`|断开控制器。返回`0` 成功，`-2` 失败|
|`enable(``controller_dds``::RequestMode mode)`|`int`|使能控制模式（CSP / CST）。返回`0` 成功，`-1` 发送失败|
|`disable()`|`int`|失能控制模式。返回`0` 成功，`-2` 失败|
|`emergencyStop()`|`void`|触发急停，该操作具有最高优先级，调用后通常不可再次使能|
|`stopCurrentMission()`|`int`|强制结束当前正在执行的任务或轨迹，保持使能状态。返回`0` 成功，`-2` 失败|
|`resetZeroPosition()`|`int`|重置软件零点。返回`0` 成功，`-1` 失败|
|`returnToZero()`|`bool`|回到零位（发送 Signal 102）。返回`true` 已发送|

## **4\.4 运动控制**

运动功能接口是 DdsController 中负责**机器人运动执行**的核心模块，覆盖从简单点动到复杂轨迹控制的完整运动能力。该模块位于控制类接口（`connect`/ `enable`等）与设置/获取接口之间，是用户完成"连接 → 使能"之后的**实际运动执行层**。所有接口均通过 DDS 信号与远端控制器通信。

# **5\. 使用说明**

该模块给出了控制器的完整使用例程，展示典型控制流程：**创建控制器 → 连接 → 使能 → 运动执行 → 去使能 → 断开连接**。

```C++
#include "dds_controller.h"

#define _USE_MATH_DEFINES
#include <cmath>

#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <fstream>
#include <iostream>
#include <mutex>
#include <sstream>
#include <string>
#include <thread>
#include <chrono>
#include <atomic>
#include <vector>
#include <algorithm>
#include <memory>

int main()
{
    // 1. 创建控制器
    auto controller = DdsController::createDdsController(88);

    // 2. 连接
    controller_dds::StartConfig config;
    config.config_name = "ir_no_ee";
    config.robot_type = 1;

    config.ee_type = 0;
    config.enable_csp_output_limit = true;
    config.enable_cst_output_limit = false;
    config.enable_error_code_check = false;
    config.enable_encoder_check = true;
    config.enable_domain_counter_check = true;
    config.gravity_compensation_enabled = false;
    std::this_thread::sleep_for(std::chrono::seconds(5));
    controller->getRobotState();
    printf("DDS 初始化完成，等待 discovery...\n");
    std::this_thread::sleep_for(std::chrono::seconds(3));
    controller->connect(config);
    std::this_thread::sleep_for(std::chrono::seconds(40));
  
  

    printf("连接成功，等待从站初始化...\n");
  
    // 3. 使能 CSP
   controller->enable(controller_dds::RequestMode::kCSP);

    std::this_thread::sleep_for(std::chrono::seconds(5));

    // 获取底盘传感器数据
    auto* dds = static_cast<DdsController*>(controller.get());
    const auto& sensor = dds->getChassisSensor();
    printf("底盘传感器: 左轮=%.3f rad/s, 右轮=%.3f rad/s\n",
           sensor.left_wheel_speed, sensor.right_wheel_speed);
    for (int i = 0; i < 8; ++i) {
        printf("  超声波[%d]: %.1f mm\n", i, sensor.ultrasonic[i]);
    }

    // 4. 底盘转圈：左转 2s → 右转 2s
    constexpr double kWheelSpeed = 0.5;  // 轮子速度 rad/s

    auto rotate_cb = [](const controller_dds::RobotState&,
                         controller_dds::Duration dt,
                         controller_dds::JointPositionCmd& cmd) {
        if (!cmd.isInitialized()) {
            cmd.enableWheel();
            cmd.setInitialized();
        }

        double t = dt.toSec();

        if (t < 2.0) {
            // 左转：左轮向后，右轮向前
            cmd.wheel.dq_d[0] =  kWheelSpeed;
            cmd.wheel.dq_d[1] =  kWheelSpeed;
            printf("[%.1fs] 左转中... 左轮: %.1f, 右轮: %.1f rad/s\n",
                   t, cmd.wheel.dq_d[0], cmd.wheel.dq_d[1]);
        } else if (t < 4.0) {
            // 右转：左轮向前，右轮向后
            cmd.wheel.dq_d[0] =  -kWheelSpeed;
            cmd.wheel.dq_d[1] = -kWheelSpeed;
            printf("[%.1fs] 右转中... 左轮: %.1f, 右轮: %.1f rad/s\n",
                   t, cmd.wheel.dq_d[0], cmd.wheel.dq_d[1]);
        } else {
            // 停止
            cmd.wheel.dq_d[0] = 0.0;
            cmd.wheel.dq_d[1] = 0.0;
            cmd.motionFinish();
            printf("[%.1fs] 转圈完成，停止\n", t);
        }
    };

    printf("开始底盘转圈 demo\n");

    // 配置 HybridTrajectory：开启轮子控制
    controller_dds::HybridTrajectoryConfig traj_cfg;
    traj_cfg.enable_wheel = true;
    dds->startHybridTrajectory(rotate_cb, traj_cfg);

    // 等待运动完成（最多等 5 秒）
    std::this_thread::sleep_for(std::chrono::seconds(5));

    // 5. 清理
    controller->disable();
    controller->disconnect();
    printf("demo 结束\n");
    return 0;
}
```

# **6\. 最佳实践**

## **6\.1 控制流程规范**

1\. **启动顺序**：创建控制器 → DDS 初始化等待 → 连接 → 等待从站初始化 → 使能 → 开始运动

2\. **关闭顺序**：停止运动 → 去使能 → 断开连接

3\. **关键等待时间**：DDS discovery 约 3 秒，从站初始化约 40 秒，切勿跳过

## **6\.2 回调函数注意事项**

- 回调在后台线程中执行，需注意线程安全（使用 `std::mutex` 或 `std::atomic` 保护共享数据）

- 回调执行时间不应过长，避免阻塞 \~100Hz 的控制循环

- 通过 `cmd.motionFinish()` 通知 SDK 运动完成

## **6\.3 安全建议**

- 在调用 `enable()` 前，务必确认机器人周围无障碍物和人员

- 调试阶段建议启用 `enable_error_code_check`、`enable_encoder_check`、`enable_domain_counter_check`

- 急停（`emergencyStop()`）后通常不可再次使能，需重启控制器

- 系统升级前务必调用 `requestUpgradePreCheck()` 完成自检（电量充足、电池无告警/保护/故障、电机已失能）

## **7\.5 日志系统**

r26\.6 内置自研统一日志封装 `zdl_logger`（对外公开头文件 `zdl_logger.h`，不暴露 spdlog 依赖）：

- 日志落盘目录、级别、保留天数可配置（`zdl_log::Config`，默认 `logs/` 目录、Info 级别、保留 10 天）

- 支持 `zdl_log::init()`、`setLevel()`、`flush()`、`flushCritical()`

- 支持关键状态快照：`logCriticalSnapshot()` 与 `formatRobotStateSnapshot()`（结合 RobotState 生成故障快照）
