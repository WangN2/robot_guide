# 移动双臂本体对比

更新日期：2026-09-15

## 当前判断

针对工厂线束布线、捋线和连接器操作：

| 优先级 | 本体 | 结论 |
|---|---|---|
| 1 | 智元精灵G2 | 四舵轮全向底盘，支持任意角度蟹行；力控和接口参数较完整，优先进入POC。 |
| 2 | 星尘Astribot S1 | 三自由度全向底盘，操作性能强；底盘速度、定位精度、力控和工业认证资料需补齐。 |
| 3 | 智动力D1 | 四轮四转并支持蟹行；负载与升降能力强，但重量约300kg，移动后精度和力控证据不足。 |
| 4 | 宇树G1-D旗舰版 | 差速底盘，不满足保持朝向横移；适合作为开发和数采平台，不是当前首选。 |
| 5 | 智动力JUNO2-SD | 差速底盘为硬伤；机械臂精度和闭环力控指标也未公开。 |

## 关键区别

智元G2的官方手册明确给出四舵轮、1.5m/s、任意角度蟹行、5自由度躯干、双7自由度力控臂、全关节力矩传感、5kHz以上力传感采样和末端24V/RS485/CAN-FD接口。这些参数与布线场景直接相关。

星尘S1的研发论文确认23自由度构成为双臂14、躯干4、头部2和全向底盘3。官网给出单臂5kg、重复精度±0.1mm和4至6小时续航，但没有公布底盘速度、定位精度和完整接口。

智动力D1符合全向蟹行需求，但属于重型平台。JUNO1-P、JUNO2-SD、L1和Z1 SDK均体现差速轮结构，无法通过软件实现纯横移。

天机Marvin M6 CCS是高性能双臂模块，不包含标准移动底盘。它的力控、精度、IP54和接口指标较好，适合评估“Marvin双臂加第三方四舵轮底盘”的集成路线，但集成成本、安全责任和整机标定需要单独计算。

## 仍未解决的共性问题

- 全向底盘横移停止后的末端整链路精度。
- 线束专用夹爪、防滑、断电保持和寿命。
- 连接器插接所需的视觉和力位混合控制。
- 工厂安全认证、外部急停、STO和网络隔离。
- 真实节拍、连续运行和2.5年回本所需的故障与人工介入数据。
