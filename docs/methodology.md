# 数据与评分方法

## 数据原则

每个参数同时记录型号、版本、来源、日期和证据等级。参数优先级如下：

1. 合同保证值或双方签字的技术协议。
2. 我方现场POC或验收实测。
3. 厂商正式用户手册、数据表。
4. 厂商官网和研发论文。
5. 销售书面回复。
6. 第三方报道和口头信息。

同一参数存在冲突时不覆盖旧值。在备注中保留不同口径，并把问题登记到问题清单。

## 布线捋线评分

评分范围为0至5分：

- 5：能力明确、参数完整，具备较强工程证据。
- 4：能力明确，仍有少量关键项需要POC。
- 3：理论可用，但工程数据或接口不完整。
- 2：存在明显限制，需要较多定制开发。
- 1：不满足主要需求。
- 0：能力缺失或无主动移动结构。

当前权重：

- 底盘全向与贴线能力：25%。
- 双臂与躯干工作空间：15%。
- 力控与柔顺能力：20%。
- 定位与视觉闭环：15%。
- SDK与末端接口成熟度：10%。
- 工业可靠性与维护：15%。

综合分只用于通过硬门槛后的排序。对于布线捋线，不能保持机身朝向横向移动的差速底盘直接标记为“不通过”，不因其他高分抵消。

双足或双轮足产品虽然可以通过步态改变横向位置，但在供应商未提供连续侧移节拍、上身扰动和末端误差前，一律标记为“待实测/待确认”，不能等同于舵轮全向底盘。产品还需通过可采购性、SDK开放、本地交付和售后资格审查；技术评分高不代表可直接采购。

## POC最低要求

- 保持身体朝向不变，连续横移2米。
- 横移停止后完成视觉重定位和线束抓取。
- 双臂协同捋线，能够检测卡滞并柔顺停止。
- 按真实工装连续运行500至1000次。
- 记录节拍、一次成功率、损伤率、人工介入、故障恢复和连续运行时长。
